 Smart City Traffic Flow Simulator

A Python-based traffic simulation and data analysis project developed using NumPy and Matplotlib in Google Colab.

📌 Project Overview

This project simulates vehicle traffic across 10 junctions over 30 days, analyzing hourly traffic patterns to identify peak congestion hours and the busiest junctions.

 Features

*  Simulates 7,200 traffic records.
*  Calculates average, minimum, and maximum traffic.
*  Identifies peak traffic hours.
*  Analyzes traffic volume across 10 junctions.
*  Visualizes traffic patterns using heatmaps.
*  Generates hourly and daily traffic graphs.
*  Compares vectorized NumPy operations with loop-based calculations.
*  Uses a fixed random seed for reproducible results.

🛠️ Technologies Used

* Python
* NumPy
* Matplotlib
* Google Colab

🚀 How to Run

1. Open Google Colab.
2. Create a new notebook.
3. Copy the project code into a code cell.
4. Run the cell to generate the simulation results and visualizations.

📊 Dataset Details

* Simulation duration: 30 days
* Number of junctions: 10
* Hours per day: 24
* Total records: 7,200

Note: The traffic data is synthetically generated for educational and analytical purposes. It does not represent actual city traffic.

🎯 Learning Outcomes

* NumPy arrays and multidimensional data.
* Random data simulation.
* Array aggregation and statistical analysis.
* Data visualization using Matplotlib.
* Vectorization and performance measurement.
